# NOOR

NOOR — это интернет-магазин женской мусульманской одежды. Проект создан на React + Vite в рамках учебной работы.

## Описание проекта

Сайт предназначен для просмотра товаров, добавления их в корзину и оформления заказа. В проекте реализованы страницы, работа с корзиной, сохранение данных в localStorage, получение данных через API и отправка POST-запроса.

## Основные функции

- Главная страница
- Каталог товаров
- Страница корзины
- Добавление товара в корзину
- Изменение количества товара
- Выбор размера
- Подсчёт общей суммы
- Сохранение корзины в localStorage
- Получение данных через API
- Отправка POST-запроса
- Навигация между страницами через React Router
