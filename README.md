# NOOR

NOOR — сайт магазина скромной одежды для мусульманок.

## Что есть на сайте

- Главная страница с товарами
- Страница "О нас"
- Корзина
- Фильтр по категориям
- Добавление товара в корзину
- Выбор размера
- Изменение количества товара
- Подсчет общей суммы
- Сохранение корзины в LocalStorage
- Получение товаров через API
- Отправка заказа через POST-запрос

## Использованные технологии

- React
- React Router DOM
- Vite
- LocalStorage
- Fetch API
